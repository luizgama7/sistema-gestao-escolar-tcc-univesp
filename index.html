Arquitetura de 3 Camadas

Arquitetura Proposta: FastAPI + MongoDB + Web/Mobile Responsivo

Infraestrutura distribuída para processamento de dados acadêmicos e disponibilização segura via web e dispositivos móveis.

1. Camada de Apresentação (Frontend)

Desenvolvida com HTML5, Tailwind CSS e Chart.js. Totalmente responsiva para navegadores desktop e dispositivos móveis, garantindo acesso universal aos gestores.

Tailwind CSS Chart.js Mobile Friendly

2. Camada de Negócio e API (Backend)

Construída em Python com FastAPI. Gerencia rotas REST, autenticação segura com tokens de sessão e inferência em tempo real com o modelo de Machine Learning.

FastAPI Scikit-Learn JWT Auth

3. Camada de Persistência (Database)

Utiliza MongoDB Atlas em nuvem para armazenamento NoSQL flexível e seguro de registros de discentes, notas, frequências e pareceres de intervenção pedagógica.

MongoDB Atlas NoSQL Cloud Storage
